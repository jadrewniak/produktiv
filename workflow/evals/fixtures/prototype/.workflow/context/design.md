# Design

Product UI conventions for this fixture. No separate token package.

- Type: system sans-serif. No display face and no webfont.
- Color: ink `#1c1917` on paper `#fafaf9`. Failure `#9f1239`. Pending `#57534e`. Action `#1d4ed8`.
- Radius: 6px on controls. The page has no radius.
- Spacing: 8px unit. Row padding 12px 16px.
- Icons: none. Do not add an icon library.
- Components: a job row is one line — name, a status word, and at most one action. No cards, shadows, or gradients.
- Vocabulary: job, pending, failed, retry.
- The status is a word. Color does not carry the state alone.
