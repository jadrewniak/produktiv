# Farewell and parting

## Problem

A caller needs farewell and parting beside greet.

## Desired outcome

`farewell("Ada")` returns `Goodbye, Ada`. `parting("Ada")` returns `Parting, Ada`.

## Acceptance / success

- `farewell("Ada")` returns `Goodbye, Ada`.
- `parting("Ada")` returns `Parting, Ada`.

## Out of scope

- Do not add any other public function.
