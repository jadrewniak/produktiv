# Ping and pong

## Problem

A caller needs a ping and a pong.

## Desired outcome

`ping("Ada")` returns `Ping, Ada`. `pong("Ada")` returns `Pong, Ada`.

## Acceptance / success

- `ping("Ada")` returns `Ping, Ada`.
- `pong("Ada")` returns `Pong, Ada`.

## Out of scope

- Do not add any other public function.
