# Wave and nod

## Problem

A caller needs a wave and a nod.

## Desired outcome

`wave("Ada")` returns `Wave, Ada`. `nod("Ada")` returns `Nod, Ada`.

## Acceptance / success

- `wave("Ada")` returns `Wave, Ada`.
- `nod("Ada")` returns `Nod, Ada`.

## Out of scope

- Do not add any other public function.
