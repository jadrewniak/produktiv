Accepted style guide

Color & contrast

Ink #172B2E: text and balance panel.

Off-white #F7F8F4: page.

Teal #006B61: primary actions and focus.

Errors pair red text with a clear instruction; success uses a written balance.

Type & spacing

System UI font stack. Heading 28–36 px; balance 36–46 px; body 16 px; field labels 14 px. Tabular numbers for amounts.

Spacing: 8, 12, 16, 24, 28 px. Cards 20 px corners; fields/buttons 9–10 px. Borders define surfaces; no decorative shadows.

Components & responsive flow

  • Wallet balance and expense list stay together.
  • Desktop: entry panel beside wallet. At 680 px and below: entry panel below wallet.
  • 44 px minimum actions; explicit field labels; visible focus.
  • Invalid input keeps label and amount. Cancel changes no wallet state.

Accepted mock presentation: blank optional label becomes “Expense”. This does not establish product behavior or a system contract.

In-memory demonstration. Reloading restores the opening balance. System fonts; original inline SVG icons; no external assets.
